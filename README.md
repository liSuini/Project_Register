# Project_Register 项目台账系统

> 一个项目一本账：覆盖前向签约立项、后向采购实施、交付验收全流程，含过程性资料与履约资料归档。

## 项目定位

面向项目全生命周期管理的台账系统，以"项目"为核心实体，串联：

- **前向（签约立项）**：商机跟踪、合同签约、立项审批
- **后向（采购实施）**：采购订单、供应商管理、实施过程记录
- **交付（验收归档）**：交付验收、结算回款、履约资料归档
- **资料中心**：过程性资料、履约资料上传、分类检索
